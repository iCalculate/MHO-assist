# 版本沿革

- **QtScrcpy 4.2.1-mho.4** · 项目迁移到 iCalculate/MHO-assist，发布当前完整 QtScrcpy 程序、内嵌识别进程、按键编辑器与实际使用的键位配置。包含鼠标轮盘操作、滚动按键历史及顶部性能面板更新。
- **v5.0.0** · 首次在 GitHub 发布 Windows x64 便携包。源码按用途分目录，加入 QtScrcpy 路径选择与键位示例，识别模板可从含中文字符的路径加载。
- **V5** · 增加三轮进度和可选连续刷。助手先核验结算或可匹配页面，再按 `Shift → [ → ] → ]` 重开。单步页面核验超时会暂停。连续刷此前已用记录、录像和模拟页面切换验证，实际手机重开流程需要在目标设备上核对。
- **V4** · 增加中英文界面、当次与累计统计，按识别、发送和黄色反馈分别计数。开始使用 SQLite 保存会话与历史，并接入 QtScrcpy 投屏工具。
- **V3** · 定位等待连续稳定几何结果，允许小幅偏移和失配后重新定位，保留金色完成箭头占位。未确认的方向键事件可以保存箭头区域诊断。
- **V2** · 增加窗口与固定框选模式，保存相对识别区域。F8 启用前可预览，目标失焦时释放已按下的键。
